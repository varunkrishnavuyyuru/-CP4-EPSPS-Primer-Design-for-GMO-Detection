# -CP4-EPSPS-Primer-Design-for-GMO-Detection
GM crop detection project: designs and validates PCR primers targeting the glyphosate-resistant CP4-EPSPS gene (AB209952.1) in soybean. Retrieves the sequence from NCBI GenBank, designs primers with Primer3Plus, and checks specificity via Primer-BLAST — a full in silico workflow for transgene detection.
